# تقرير الأرباح والخسائر

<!-- TODO: ar translation — see en/p&l.md for source content -->

تقرير الأرباح والخسائر يُظهر الإيرادات والمصاريف وصافي الربح لفترة معينة.

## افتح التقرير

**التقارير → الأرباح والخسائر**.

* اختر النطاق الزمني.
* اختر المقارنة (الفترة السابقة أو الموازنة).

## التعمق

كل سطر قابل للنقر. انقر "الإيرادات" لتفصيلها حسب المنتج.

## التصدير

PDF أو Excel أو CSV.

## مقالات ذات صلة

* الميزانية العمومية
* المبيعات حسب المنتج
