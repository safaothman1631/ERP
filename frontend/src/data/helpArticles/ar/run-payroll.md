# تشغيل الرواتب

<!-- TODO: ar translation — see en/run-payroll.md for source content -->

تشغيل الرواتب شهرياً يتم في أربع نقرات.

## الخطوات

1. **الرواتب → دورات الرواتب → + دورة جديدة**.
2. اختر فترة الدفع.
3. راجع قائمة الموظفين.
4. اضغط **احسب**.
5. اضغط **اعتمد**.

## دفع الرواتب

بعد الاعتماد، يُولّد ملف بنكي للتحميل في بوابة بنكك.

## مقالات ذات صلة

* إضافة موظف
* قسائم الدفع
