# إغلاق نهاية اليوم

<!-- TODO: ar translation — see en/end-of-day.md for source content -->

إغلاق نهاية اليوم (تقرير Z) هو طقس الكاشير لإغلاق الصندوق وطباعة الملخص.

## الخطوات

1. سجّل الدخول كأمين صندوق أو مدير.
2. اضغط **إنهاء الوردية**.
3. أدخل عدد كل فئة عملة.
4. سيُحسب الفرق ويُطبع تقرير Z.

## بعد الإغلاق

* لا يمكن تسجيل مبيعات على الوردية المغلقة.
* تُفرّغ صناديق البيانات الخارجة.

## مقالات ذات صلة

* إدارة درج النقود
* وضع عدم الاتصال
