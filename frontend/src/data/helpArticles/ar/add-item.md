# إضافة منتج

<!-- TODO: ar translation — see en/add-item.md for source content -->

المنتجات هي ما تبيعه. كل منتج له سعر ووحدة وحسابات افتراضية.

## افتح النموذج

**المخزون → المنتجات → + منتج جديد**.

## الحقول المطلوبة

* **الاسم**.
* **النوع** — سلعة (مخزّنة) أو خدمة.
* **سعر البيع** و **سعر الشراء**.
* **حساب المبيعات**.

## حقول اختيارية

* **SKU** و **الباركود**.
* **مجموعة الضرائب**.
* **الفئات** و **العلامات**.

## مقالات ذات صلة

* فئات المنتج
* جرد المخزون
