# إعداد ضريبة القيمة المضافة

<!-- TODO: ar translation — see en/vat-setup.md for source content -->

ضريبة القيمة المضافة في العراق ليست شاملة بعد — إقليم كردستان يطبق ضريبة مبيعات إقليمية، بينما العراق الاتحادي يطبق VAT تدريجياً.

## اختر نموذجك

**الإعدادات → الضرائب → المنطقة**:

* **إقليم كردستان**.
* **العراق الاتحادي**.
* **مختلط**.

## مجموعات الضرائب

* النسبة القياسية.
* المعفى.
* صادرات بنسبة صفر.

## مقالات ذات صلة

* الضريبة المقتطعة
* معدلات الضرائب لكل منطقة
