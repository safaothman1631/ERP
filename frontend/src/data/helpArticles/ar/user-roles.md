# أدوار المستخدمين والصلاحيات

الأدوار تجمع الصلاحيات. Zoho Kurdish يقدم مجموعة من الأدوار المضمنة ويسمح بأدوار مخصصة.

## الأدوار المدمجة

* **مالك** — كل الصلاحيات.
* **مدير** — كل الصلاحيات عدا الفوترة.
* **محاسب** — الدفاتر والضرائب.
* **كاشير POS**.
* **مشاهد** — للقراءة فقط.

## أدوار مخصصة

**الإعدادات → الأدوار → + دور جديد**.

## التعيين

عيّن دوراً واحداً للمستخدم.
