# إنشاء فاتورة

<!-- TODO: ar translation — see en/create-invoice.md for source content -->

الفوترة هي الشاشة الأكثر استخداماً في Zoho Kurdish.

## افتح النموذج

من الشريط الجانبي: **الفوترة → الفواتير → + فاتورة جديدة**.

## الحقول

* **العميل** — اختر من القائمة أو أنشئ سريعاً.
* **رقم الفاتورة** — تلقائي.
* **تاريخ الفاتورة** و **تاريخ الاستحقاق**.

## بنود الفاتورة

أضف بنوداً تتضمن المنتج والكمية والسعر والضريبة.

## الإجراءات

* **حفظ كمسودة**.
* **حفظ وإرسال** — يقفل الفاتورة ويرسلها للعميل مع رابط دفع.
* **حفظ كـ PDF**.

## مقالات ذات صلة

* الفواتير المتكررة
* مشاركة رابط الدفع
