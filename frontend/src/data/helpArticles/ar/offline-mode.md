# وضع عدم الاتصال

<!-- TODO: ar translation — see en/offline-mode.md for source content -->

عند انقطاع الإنترنت، Zoho Kurdish يواصل البيع. نقاط البيع تخزن السلة والمبيعات في IndexedDB وتُزامن عند عودة الاتصال.

## كيف يعمل

عند أول فتح، نخزّن:

* جميع منتجات الموقع الفعّال.
* جميع عملاء POS.
* الأسعار والضرائب الحالية.

## أثناء عدم الاتصال

* يمكنك البيع نقداً.
* طباعة الإيصالات.

## لا يمكن

* قبول بطاقات عبر بوابة إلكترونية.
* رؤية منتجات لم تُخزَّن مسبقاً.

## عند العودة للاتصال

يظهر شريط "جاري المزامنة..." وينتهي عادةً خلال ٥ ثوانٍ.
