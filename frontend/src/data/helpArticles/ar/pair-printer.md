# إقران طابعة الإيصالات

<!-- TODO: ar translation — see en/pair-printer.md for source content -->

معظم الطابعات الحرارية المستخدمة في العراق متوافقة مع ESC/POS: Epson، Bixolon، Star، ونسخها الصينية. Zoho Kurdish يدعمها كلها.

## ما تحتاجه

* طابعة حرارية 58 أو 80 مم.
* اتصال Bluetooth أو USB.
* الطابعة قيد التشغيل.

## الإقران عبر Bluetooth

1. افتح **الإعدادات → الأجهزة → الطابعات**.
2. اضغط **إقران طابعة جديدة**.
3. اختر جهازك من نافذة Bluetooth.
4. حدد عرض الورق (58 أو 80 مم).
5. اختر pin درج النقود (2 أو 5).
6. اضغط **طباعة تجريبية**.

## مقالات ذات صلة

* إدارة درج النقود
* شاشة المطبخ
