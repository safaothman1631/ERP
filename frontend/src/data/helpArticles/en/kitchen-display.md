# Kitchen display system (KDS)

Restaurants use a kitchen display instead of paper tickets to show new orders in the kitchen. Zoho Kurdish has a built-in KDS.

## Set up

1. Pick a tablet or monitor and connect it to the kitchen Wi-Fi.
2. Open `https://app.zoho-kurdish.iq/pos/kitchen` and sign in.
3. Pick your **station** — Grill, Cold, Hot, Bar, etc.

Only orders that include items in this station appear on this screen.

## How it works

* New orders appear as cards.
* Tap a card to start cooking — the card turns orange.
* Tap **Done** to mark it ready — the card disappears and a chime plays at the counter.

## Configuration

Map products to stations from **Inventory → Items → Edit → KDS station**. An item without a station goes to the default "Grill" line.

## Multiple kitchens

Each station can run on its own display. Multiple displays per station stay in sync via real-time updates.
