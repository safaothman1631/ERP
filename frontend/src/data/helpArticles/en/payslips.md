# Payslips

Each payroll run produces a payslip per employee. Payslips can be downloaded as PDF, emailed, or made available in the self-service portal.

## Auto-email

By default, posting a pay run emails each employee their payslip with the password being their national ID (configurable from **Settings → Payroll**).

## Self-service portal

Employees with a "Self-service" login can sign in and download past payslips from **My profile → Payslips**.

## Re-issue

If a payslip needs correction, edit the pay run, re-post, and the corrected payslip is re-emailed automatically.

## Year-end summary

End of year produces a consolidated annual summary that doubles as the tax certificate for the employee.
