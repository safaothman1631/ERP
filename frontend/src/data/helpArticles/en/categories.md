# Item categories

Categories organise items into a hierarchy. Use them for reporting ("sales by category"), POS layout, and tax rules.

## Create a category

**Inventory → Categories → + New**. Each category has a name in Kurdish/Arabic/English plus an optional parent for nesting.

## Assign items

From the item form, pick a category. You can also bulk-assign from the item list via the "Move to category" action.

## Use in POS

On the POS terminal, the top-bar categories are configurable. Pin your top categories first; the rest are reachable via "More".

## Reports

**Reports → Sales by category** shows revenue, COGS, and margin per category. Comparing categories across time is the fastest way to see what is and isn't working.
