# User roles & permissions

Roles bundle permissions. Zoho Kurdish ships with a set of common roles and lets you build custom ones.

## Built-in roles

* **Owner** — every permission including billing.
* **Admin** — every permission except billing.
* **Accountant** — full books, no HR.
* **POS cashier** — POS terminal only.
* **Viewer** — read-only across everything.
* **Self-service** — own profile + payslips only.

## Custom roles

**Settings → Roles → + New role**. Pick a starting role, then tick or untick individual permissions. Save.

## Assign

Assign a role on the user record. A user can have only one role (per company).

## Audit

Every permission grant or revoke is logged in the audit log with timestamp and actor.

## Common issues

* **User can't see a button** — they lack the permission. Edit the role.
* **Lock-out** — remove the role from a user instead of deleting the user; you can re-grant later.
