# Stock count

A stock count (also called a physical count or inventory count) compares what's on the shelf to what Zoho Kurdish thinks. Differences become stock adjustments.

## Start a count

**Inventory → Stock counts → + New count**.

* Pick a location.
* Pick a filter (whole location, one category, one shelf).
* Click **Start**.

The count is now open. Stock movements during the count are tracked separately so you don't double-count.

## Count

Walk the shelves with a phone or tablet open to the count screen. For each item:

* Scan the barcode (or pick from the list).
* Type the physical count.

Counts you've entered show as "counted"; pending items are highlighted.

## Reconcile

When you're done, tap **Reconcile**. The system shows differences:

* Items found vs system → variance with sign and value.
* Items expected not found → write off.

Confirm to post stock adjustment journal entries. Or, save as draft for a supervisor to review first.

## Common issues

* **Phantom positive variance** — usually a missed sale or a transfer not booked.
* **Phantom negative variance** — receivable not booked, shrinkage, or counting error.
