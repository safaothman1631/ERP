# Add an employee

Employees are the people you pay through payroll. Each employee has a profile, a contract, and (optionally) a user login.

## Create the profile

**HR → Employees → + New employee**.

* **Name, ID, phone, email**.
* **National ID** and **passport** (for non-citizens).
* **Bank details** — for salary deposit.
* **Hire date** and **employment type** — full-time, part-time, contractor.

## Set up payroll

On the same form, the **Payroll** tab asks for:

* **Gross monthly salary** or hourly rate.
* **Allowances** — housing, transport, family.
* **Deductions** — loan repayments, advances.
* **Tax status** — single / married / dependents.

## Optional login

Tick **Create user login** to give the employee app access. Pick a role; **Self-service** is fine for most employees so they can view their own payslips and request leave.

## Common issues

* **Bank details wrong** — corrected on the next pay run.
* **Tax bracket wrong** — update **Tax status**; the next payroll recalculates.
