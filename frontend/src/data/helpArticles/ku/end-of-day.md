# کۆتایی ڕۆژ

کۆتایی ڕۆژ (یان Z-report) ڕیتواڵی کارمەندی کاشییە بۆ داخستنی تەلڵ، چاپکردنی کورتە و قفڵکردنی شیفت.

## ئەو کارانە دەکات

1. پارە بەپێی هەر دەنومیناسیون دەژمێرێت.
2. باڵانسی چاوەڕوانکراو دەژمێرێت.
3. جیاوازییەکان تۆمار دەکات.
4. Z-report چاپ دەکات.
5. شیفت قفڵ دەکات.

## هەنگاوەکان

1. وەک کارمەند یان بەڕێوەبەر بچۆ ژوور.
2. کلیک لە **کۆتایی شیفت** بکە.
3. ژمارەی هەر دەنومیناسیون بنووسە.
4. دوای دڵنیابوون، Z-report چاپ دەکرێت.

## دوای داخستن

* هیچ فرۆشتنێک ناتوانێت لە شیفتی داخراودا تۆمار بکرێت.
* outbox پاک دەکرێتەوە.

## بابەتە پەیوەندیدارەکان

* بەڕێوەبردنی پارە
* دۆخی ئۆفلاین
