# دامەزراندنی VAT

VAT لە عێراق هێشتا گشتی نییە — هەرێمی کوردستان باجی فرۆشتنی ناوچەیی بەکار دەهێنێت، عێراقی فێدراڵ VAT بەرە بەرە چەسپاندوە. Zoho Kurdish هەردووکیان کار دەکات.

## مۆدێلی باج هەڵبژێرە

**ڕێکخستن → باجەکان → ناوچە**. هەڵبژێرە:

* **هەرێمی کوردستان** — باجی فرۆشتنی KRG.
* **عێراقی فێدراڵ** — جەدوەلی باجی فێدراڵ.
* **تێکەڵ** — هەردوو.

## گرووپی باج

گرووپی پێشدامەزراو:

* ڕێژەی ستاندارد (لە ئێستادا ٠٪ فێدراڵ)
* بێبەش
* ڕێژەی سفر بۆ هەناردە

## پێشاندانی ڕیسیت

ڕیسیت و فاکتور خشتەی باج بەپێی گرووپ پیشان دەدات. بۆ فاکتورە گەورەکان، QR-ـی e-Fakhata خۆکار دادەنرێت.

## بابەتە پەیوەندیدارەکان

* پاش بەرگرتنی باج
* ڕێژەی باج بۆ هەر ناوچەیەک
