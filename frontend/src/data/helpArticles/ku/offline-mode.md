# دۆخی ئۆفلاین

کاتێک ئینتەرنێت دەکوژێتەوە، Zoho Kurdish بەردەوام دەبێت لە فرۆشتن. POS داتاکانی سەبەتە، فرۆشتن و پارەدان لە IndexedDB پاشەکەوت دەکات؛ کاتێک ئینتەرنێت دەگەڕێتەوە، خۆکار هاوبەشی دەکات.

## چۆن کار دەکات

یەکەم جار کە POS دەکەیتەوە، ئەم زانیاریانە کاش دەکەین:

* هەموو بەرهەمەکانی شوێنە کاراکەت.
* هەموو کڕیارە POS-ـیەکان.
* نرخ و ڕێژەی باجی ئێستا.

لە ئۆفلاین:

* فرۆشتن وەکو ئاسایی دەکەیت.
* ڕیسیت چاپ دەکەیت (چاپکەر پێویستی بە ئینتەرنێت نییە).
* پارەی نەختی و کارتی تۆمارکراو وەردەگریت.

ناتوانیت:

* پارە لە کارت وەربگریت لە ڕێگەی gateway.
* بەرهەمی نوێی نا-کاشکراو ببینیت.

## گەڕانەوەی ئینتەرنێت

کاتێک ئامێر دەگەڕێتەوە، پانیلێک پیشان دەدات "هاوبەشی N مامەڵە...". outbox وەک ئاسایی ٥ چرکە دەخایەنێت.

## ڕەفتاری چاک

* پێش گەڕانەوەی ماڵەوە، کۆتایی ڕۆژ بکە.
* دۆنگڵی موبایل هەڵگرە بۆ پاڵپشت.

## بابەتە پەیوەندیدارەکان

* کۆتایی ڕۆژ
