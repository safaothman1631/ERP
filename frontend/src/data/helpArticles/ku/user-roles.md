# ڕۆڵی بەکارهێنەر

ڕۆڵ گرووپی دەسەڵاتە. Zoho Kurdish چەند ڕۆڵی ئامادە دەنێرێت و ڕێگەت پێ دەدات تایبەت دروست بکەیت.

## ڕۆڵە پێشدامەزراوەکان

* **خاوەن** — هەموو دەسەڵاتەکان.
* **ئەدمین** — هەموو دەسەڵاتەکان جگە لە بل کردن.
* **ژمێریار** — کتێب و باجەکان.
* **کارمەندی POS** — تەنها POS.
* **بینەر** — تەنها خوێندنەوە.

## ڕۆڵی تایبەت

**ڕێکخستن → ڕۆڵەکان → + ڕۆڵی نوێ**.

## دانان

لە تۆماری بەکارهێنەر ڕۆڵ دابنێ. بەکارهێنەر یەک ڕۆڵی هەیە.

## تۆمارکردن

هەر گۆڕانکارییەکی دەسەڵات لۆگ دەکرێت لە لۆگی چاودێری.

## بابەتە پەیوەندیدارەکان

* لۆگی چاودێری
