# بەستنی چاپکەری ڕیسیت

زۆربەی چاپکەرە تەرماڵەکانی عێراق ESC/POS ـن: Epson TM, Bixolon, Star و کۆپی چینییەکان. Zoho Kurdish هەموویان پشتگیری دەکات.

## پێداویستی

* چاپکەری تەرماڵی ٥٨ یان ٨٠ ملم.
* پەیوەندی Bluetooth یان USB.
* چاپکەر کارا.

## بەستن لە ڕێگەی Bluetooth

1. **ڕێکخستن → هاردوێر → چاپکەرەکان**.
2. کلیک لە **بەستنی چاپکەری نوێ** بکە.
3. براوزەر دیالۆگی Bluetooth دەکاتەوە — ئامێرەکەت هەڵبژێرە.
4. پانی کاغەز هەڵبژێرە (٥٨ یان ٨٠ ملم).
5. پنی پارەدان هەڵبژێرە (زۆربەی چاپکەرەکان ٢، هەندێکیان ٥).
6. کلیک لە **تاقیکردنەوەی چاپکردن** بکە.

## بەستن لە ڕێگەی USB

پێویستت بە ئاژانسی چاپ هەیە. لێرە دایبگرە بۆ Windows/macOS/Linux.

## کێشە باوەکان

* **کاغەز نییە** — کاغەزەکە بگۆڕە.
* **پیتی نادروست** — codepage-ـی نادروست. "Arabic 864" یان "Windows-1256" هەڵبژێرە.
* **پارەدان نەکراوەتەوە** — پنی دیکە تاقی بکەرەوە (٢ ↔ ٥).

## بابەتە پەیوەندیدارەکان

* بەڕێوەبردنی پارە
* پیشاندەری چێشتخانە
