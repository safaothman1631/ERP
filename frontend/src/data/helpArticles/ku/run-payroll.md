# جێبەجێکردنی مووچە

مووچە کارێکی مانگانەیە. Zoho Kurdish چوار کلیک بەس دەخوازێت.

## هەنگاوەکان

1. **مووچە → مووچەکان → + مووچەی نوێ**.
2. ماوەی پارەدان هەڵبژێرە.
3. لیستی کارمەندان پشکنە — هەر یەکێک کۆ، خەرجی، داشکاندن، باج، نێت پیشان دەدات.
4. کلیک لە **حیساب** بکە.
5. کلیک لە **پۆست** بکە بۆ تەواوکردن.

## پارەدانی کارمەندان

دوای پۆست، دوگمەی **پارەدان** فایلێکی بانکی دروست دەکات بۆ بارکردن لە پۆرتاڵی بانک.

## کێشە باوەکان

* **باجی هەڵە** — دۆخی باجی کارمەند پشکنە.
* **نێتی نێگەتیڤ** — داشکاندن لە کۆ زیاترە. ڕاستی بکەرەوە.

## بابەتە پەیوەندیدارەکان

* زیادکردنی کارمەند
* پێسلیپ
