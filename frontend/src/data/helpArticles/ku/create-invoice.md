# دروستکردنی فاکتور

فاکتور زۆرترین بەکارهێنراوە لە Zoho Kurdish. لێرە چۆن یەکێکی نوێ دروست دەکەیت.

## فۆڕم بکەرەوە

لە لاتەنیشت، کلیک لە **فاکتور → فاکتورەکان → + فاکتوری نوێ** بکە.

## ناونیشانی فاکتور پڕ بکەرەوە

* **کڕیار** — کڕیارێکی هەبوو هەڵبژێرە، یان ناوی نوێ بنووسە.
* **ژمارەی فاکتور** — خۆکار دانراوە.
* **بەرواری فاکتور** و **بەرواری کۆتایی**.
* **ژمارەی ئاماژە** — ئیختیاری، بۆ PO ـی کڕیار.

## درۆڕەکان زیاد بکە

کلیک لە **زیادکردنی درۆڕ** بکە. هەر درۆڕێک پێویستی بە: بەرهەم، ژمارە، نرخ، داشکاندن، باج، هەژمار هەیە.

## کۆتایی پشکنین

پەنلی لای ڕاست کۆ، داشکاندن، باج و کۆی گشتی پیشان دەدات.

## پاشەکەوتکردن و ناردن

* **پاشەکەوتکردن وەک ڕەشنووس** — هێشتا گۆڕانکاری دەکرێت.
* **پاشەکەوتکردن و ناردن** — فاکتور دادەخرێت و بە ئیمەیڵ/WhatsApp بۆ کڕیار دەنێرین.
* **پاشەکەوتکردن وەک PDF** — بۆ ناردنی ئۆفلاین.

## بابەتە پەیوەندیدارەکان

* فاکتوری دووبارەبووەوە
* بەستەری پارەدان
