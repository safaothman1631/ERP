# زیادکردنی بەرهەم

بەرهەمەکان شتانێکن کە دەفرۆشیت — بەرهەم یان خزمەتگوزاری. هەر بەرهەمێک نرخ، یەکە و هەژماری بنەڕەتی هەیە.

## فۆڕم بکەرەوە

**ئەنبار → بەرهەمەکان → + بەرهەمی نوێ**.

## خانە پێویستەکان

* **ناو** — ئەوەی کڕیار لە ڕیسیت دەیبینێت.
* **جۆر** — بەرهەم یان خزمەتگوزاری.
* **نرخی فرۆشتن** و **نرخی کڕین**.
* **هەژماری فرۆشتن** — زۆربەی کات "داهات".

## خانە ئیختیاریەکان

* **SKU** و **بارکۆد**.
* **گرووپی باج**.
* **پۆلێن**، **تاگ**.
* **وێنە**.

## نرخی فرۆشگا

بۆ داشکاندنی فرۆشگا/کارمەند، لیستی نرخ دروست بکە لە **ڕێکخستن → لیستی نرخ**.

## بابەتە پەیوەندیدارەکان

* پۆلێنکردن
* ژماردنی ئەنبار
