# ڕاپۆرتی قازانج و زیان

P&L (یان "بەیانی داهات") داهات، خەرجی و قازانج/زیانی نێت بۆ ماوەیەک پیشان دەدات.

## ڕاپۆرت بکەرەوە

**ڕاپۆرتەکان → P&L**.

* ماوەی بەروار هەڵبژێرە.
* بەراورد — لەگەڵ ماوەی پێشوو، ساڵی پێشوو، یان بودجە.

## بڕۆ بۆ ناوەوە

هەر دێرێک کلیک کراوە. کلیک لە "داهات" بکە بۆ دابەشکردن بەپێی بەرهەم؛ کلیک لە بەرهەم بکە بۆ فاکتورەکان.

## فلتەرەکان

* **شوێن** — بۆ فرۆشگا چەند شوێنییەکان.
* **بەش** یان **پڕۆژە**.
* **پارە** — بنەڕەت یان دەستی نیشتمانی.

## بابەتە پەیوەندیدارەکان

* باڵانس شیت
* فرۆشتن بەپێی بەرهەم
