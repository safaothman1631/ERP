# گەڕاندنەوەی پارە

گەڕاندنەوەی پارە بۆ کڕیار کاتێک کاڵا دەگەڕێنێتەوە یان خزمەتگوزاری وەرنەگرتووە. گەڕاندنەوە بەرامبەر فرۆشتنی بنەڕەتی تۆمار دەکرێت و ئەنبار دەگەڕێنرێتەوە.

## گەڕاندنەوەی پارە دروست بکە

1. لە POS، **دۆزینەوەی فرۆشتن** کلیک بکە.
2. فرۆشتن دەکرێتەوە. **گەڕاندنەوە** کلیک بکە.
3. کاڵا هەڵبژێرە — دەکرێ بەشێکی.
4. شێوازی گەڕاندنەوە هەڵبژێرە — نەختی، کارت، کرێدیتی فرۆشگا.
5. دڵنیا بکەرەوە.

ڕیسیتی گەڕاندنەوە چاپ دەکرێت.

## بێ ڕیسیت

ئەگەر کڕیار ڕیسیت ون کردبێت، بەڕێوەبەر دەتوانێت ڕێگە بدات.

## گەڕاندنەوەی کارت

بۆ فرۆشتنی کارت لە ڕێگەی Stripe، گەڕاندنەوە بۆ کارتی بنەڕەتی دەگەڕێتەوە.

## بابەتە پەیوەندیدارەکان

* هەڵوەشاندنەوەی فرۆشتن
* وەسڵی پارەدان
