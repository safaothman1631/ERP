# ERPIQ — یەک‌پەڕەی سەرمایە‌وەرگرتن (Fundraising One-Pager)

> **ئاگاداری:** هەموو ژمارەی پارە/بڕی سەرمایە لێرە **خەمڵاندنی پلاندانانن (planning figures)**، نەک ڕاوێژی دارایی یان وەبەرهێنان. پێش هەر گفتوگۆیەکی فەرمی لەگەڵ ڕاوێژکاری یاسایی/دارایی پشتڕاست بکەرەوە.

---

## یەک‌پەڕە (One-Pager)

### 🧩 کێشە (Problem)
کەرتی SMB-ی عێراق (دوکان، ڕیستۆرانت، دەرمانخانە، کۆمپانیای بچووک) هیچ سیستەمێکی ERP/POS-ی **کوردی/عەرەبی، عێراق-تەرخان**ی بەردەست نییە:
- سیستەمە جیهانییەکان (Zoho, SAP, QuickBooks) **بە کوردی نین**، RTL باش پشتگیری ناکەن، و IQD/باجی عێراق/e-Fakhata پشتگیری ناکەن.
- پچڕانی کارەبا بەردەوامە → POS-ی online-only ناکار دەبێت.
- پارەدانی ناوخۆیی (FastPay, Zain Cash, Qi) لە سیستەمە جیهانییەکان نییە.
- **e-Fakhata** (فاکتوری ئەلیکترۆنی وەزارەتی دارایی) لە ڕێگایە → هەموو بازرگان پێویستی بە سیستەمی پابەند دەبێت.

### 💡 چارەسەر (Solution)
**ERPIQ** — سیستەمێکی ERP/بازرگانی تەواو (وەک Zoho One) بەڵام بۆ عێراق ساز کراوە:
- زیاتر لە ٣٠ مۆدیوول (فاکتور، POS، ئەنبار، CRM، HR، پڕۆژە، دارایی...) بە کوردی سۆرانی + عەرەبی + ئینگلیزی، RTL-first.
- **POS-ی offline-first** (IndexedDB) — لە کاتی پچڕانی کارەبا کار دەکات.
- IQD cash drawer، Arabic-Indic digits، فۆرماتی فاکتوری عێراقی، Hijri calendar.
- e-Fakhata e-invoicing (XML + XAdES-BES signing + MoF queue) — ئامادە بۆ پابەندبوون.
- پارەدانی ناوخۆیی (FastPay/Qi/Zain scaffold) + Stripe بۆ SaaS billing.

### ⏰ بۆچی ئێستا؟ (Why Now)
- **مەرجی e-Fakhata**: وەزارەتی دارایی فاکتوری ئەلیکترۆنی فەرز دەکات → هەموو بازرگانی فەرمی پێویستی بە سیستەمی پابەند دەبێت. ئەمە **catalyst**ـی بازاڕە.
- دیجیتاڵبوونی پارەدان لە عێراق خێرا گەشە دەکات (FastPay, Zain Cash).
- بازاڕ بەتاڵە لە ئۆفەری کوردی/عەرەبیی ڕەسەن — یەکەم mover-ی جددی دەتوانێت بازاڕ بگرێت.

### 📊 بازاڕ (Market — Iraq SMB)
- عێراق ~٤٠+ ملیۆن دانیشتوو؛ سەدان هەزار SMB (دوکان/ڕیستۆرانت/دەرمانخانە/کۆمپانیای بچووک).
- هەرێمی کوردستان + عێراقی فیدراڵی — بازاڕی سەرەتایی، دواتر فراوانبوون بۆ وڵاتانی دراوسێ.
- مۆدێلی SaaS مانگانە بە IQD/USD (پلانی نرخ: ٣٠k / ٨٠k / ٢٠٠k IQD مانگانە؛ ≈ $٢٥ / $٦٠ / $١٥٠ — **خەمڵاندن**).
- *(ژمارەی وردی TAM/SAM/SOM دەبێت بە سەرچاوەی پشتڕاستکراو دابین بکرێت — لێرە نەخراون چونکە بەردەست نین.)*

### 🏰 مۆڵە (Moat)
1. **لۆکالایزەیشنی قووڵ**: کوردی سۆرانی ڕەسەن + عەرەبی + RTL + IQD + باجی عێراق + e-Fakhata — کۆپیکردنی ئەمە بۆ ڕکابەری جیهانی گران و کاتبەرە.
2. **Offline-first POS** بۆ واقیعیەتی کارەبای عێراق.
3. **یەکپارچەیی ناوخۆیی** (FastPay/Zain/Qi + MoF e-Fakhata) — پەیوەندی + پشتڕاستکردن لەگەڵ دامەزراوە ناوخۆییەکان.
4. **فراوانی مۆدیوول**: ٣٠+ مۆدیوول لە یەک سیستەمدا — switching cost بەرز.

### 📈 پلانی Traction
- **ئێستا**: کۆدبەیسی فراوان (frontend + backend + ٣٠ مۆدیوول + POS + e-Fakhata + payments scaffold)، دیپلۆیکراو (Vercel + Cloud Run)، بەڵام **پێش-داهات** (demo data).
- **قۆناغی ٠ (مانگ ٠–٣)**: ١–٣ design partner (دووکان/ڕیستۆرانت لە هەولێر/بەغدا)، P0 (ئاسایش + دروستی دارایی).
- **قۆناغی ١ (مانگ ٣–٩)**: e-Fakhata verified، payments کارا، **٥–١٥ کڕیاری پارەدەر** (یەکەم داهات).
- **قۆناغی ٢ (مانگ ٩–١٨)**: هەر ١٠ مۆدیوول production، ٥٠+ کڕیار، SOC 2 prep.
- **قۆناغی ٣ (مانگ ١٨–٣٠)**: **١٠٠+ کڕیار**، SOC 2/ISO، AI، فرە-کۆمپانیا.

### 💰 بەکارهێنانی سەرمایە بەپێی قۆناغ (Use of Funds)
| قۆناغ | بەکارهێنان |
|-------|-------------|
| ٠ | کیانی یاسایی (LLC) + یەکەم هایەر (CTO + senior backend) + P0 (ئاسایش/دارایی) + design partner |
| ١ | تیم (١٠–١٤) + e-Fakhata verification + payment credentials + یەکەم کڕیار + پشتیوانی |
| ٢ | فراوانکردنی تیم (١٨–٣٠) + observability/DR + SOC 2 prep + فرۆش |
| ٣ | فراوانبوون (٣٠–٥٠+) + بڕواننامە (SOC2/ISO) + AI + بازاڕگەری |

### 🎯 داواکاری (Ask — Planning Ranges Only)
> **ئەمانە تەنها بازنەی پلاندانانن — نەک ڕاوێژ. بڕی ڕاستەقینە بەپێی benchmark-ی بازاڕ + ڕاوێژکاری دارایی دیاری دەکرێت.**

- **Pre-seed / Seed** (بۆ قۆناغی ٠–١، گەیشتن بە یەکەم داهات): بازنەی خەمڵێنراو **$٣٠٠k – $٧٥٠k**.
- **Series A** (بۆ قۆناغی ٢–٣، مەزنبوون بۆ ١٠٠+ کڕیار + بڕواننامە): بازنەی خەمڵێنراو **$٢M – $٥M**.
- ئامانج: ١٨–٢٤ مانگ runway بۆ هەر بازنەیەک.
