# ڕانبووکی Pilot + Onboarding — ERPIQ

> ڕانبووکێکی دووبارە-بەکارهێنراو (repeatable runbook) بۆ بردنی کڕیارێکی نوێ لە «pilot» بۆ «پارەدەر». تایبەت بۆ بازاڕی عێراق (offline POS، IQD، WhatsApp).
> **خاوەن:** Product / Implementation Manager + Support / CS Lead. هەموو مەترسایەکان (metrics) خەمڵاندنی سەرەتاییە و بەپێی داتای ڕاستەقینە دەگۆڕێن.

---

## 0. هەڵبژاردنی Design Partner / Pilot

| پێوەر | مەرج |
|-------|------|
| جۆری بزنس | دووکان، ڕیستۆرانت، دەرمانخانە، یان کۆمپانیای بچووکی خزمەتگوزاری (کەرتی سەرەکی ERPIQ) |
| قەبارە | SMB — ١–٢٠ کارمەند (نە زۆر گەورە، نە تاک-کەس) |
| شوێن | هەولێر یان بەغدا (نزیک بۆ پشتیوانی ڕووبەڕوو لە قۆناغی سەرەتا) |
| ئامادەیی | خاوەنی بزنس ئامادەی هاوکاری + فیدباک + ٣٠–٩٠ ڕۆژ بەشداری |
| ئامێر | لانیکەم ١ کۆمپیوتەر/تابلێت + (بۆ POS) چاپکەری ٥٨/٨٠mm + cash drawer |

✅ گرێبەستی pilot واژۆ بکرێت (مەرجی نهێنی + فیدباک + ئاکامی exit-to-paid). بڕوانە `templates/pilot-agreement.md` ئەگەر بەردەستە.

---

## 1. پێش-Pilot (Pre-Pilot Setup) — هەفتەی ٠

- [ ] دروستکردنی tenant/org لە سیستەم بۆ کڕیار.
- [ ] ڕێکخستنی زمان (کوردی/عەرەبی/ئینگلیزی) + calendar (Gregorian/Hijri) + digit preference.
- [ ] ڕێکخستنی زانیاری کۆمپانیا: ناو، ناونیشان، پارێزگا (١٨ governorate)، VAT status، `commercial_registration_no`.
- [ ] هەڵبژاردنی Chart of Accounts template (بەپێی کەرت).
- [ ] دروستکردنی بەکارهێنەران + ڕۆڵەکان (RBAC: owner/accountant/cashier/...).
- [ ] ڕێکخستنی currency (IQD سەرەکی، USD/EUR ئەگەر پێویست).
- [ ] دیاریکردنی KPI-ی سەرکەوتن لەگەڵ کڕیار (لە بەشی ٤).

---

## 2. هەنگاوەکانی گواستنەوەی داتا (Data Migration)

- [ ] **بەرهەمەکان (Items)**: import-ی لیستی بەرهەم/خزمەت (CSV/Excel) — کۆد، ناو، نرخ، باج، یەکە.
- [ ] **کڕیار/دابینکار (Contacts)**: import-ی customers + vendors.
- [ ] **باڵانسی سەرەتایی**: opening balances بۆ هەژمارەکان (لەگەڵ ژمێریار).
- [ ] **ئەنبار (Inventory)**: opening stock بۆ هەر شوێن/location.
- [ ] **فاکتورە کۆنەکان (ئیختیاری)**: ئەگەر پێویست، import-ی فاکتورە چالاکەکان.
- [ ] **پشتڕاستکردن**: کۆی باڵانس + ئەنبار لەگەڵ سیستەمی کۆن یەک بخرێتەوە (reconciliation).
- [ ] backup-ی یەکەم وەربگیرە دوای migration.

> تێبینی: بۆ کڕیاری بێ-سیستەمی کۆن (کاغەز)، migration دەبێتە data entry-ی دەستی — کاتی زیاتر تەرخان بکە.

---

## 3. ڕاهێنان (Training)

- [ ] **Session 1 — بنەماکان**: navigation، dashboard، زمان/RTL، ڕۆڵەکان.
- [ ] **Session 2 — کاری ڕۆژانە بەپێی ڕۆڵ**:
  - فرۆشیار/کاشێر: POS، فاکتور، وەرگرتنی پارە، چاپی ڕیسیت.
  - ژمێریار: هەژمار، ژوورناڵ، ڕاپۆرت، e-Fakhata.
  - بەڕێوەبەر: ئەنبار، کڕین، ڕاپۆرتی فرۆش.
- [ ] **Session 3 — تایبەتی عێراق**: e-Fakhata submission، IQD cash drawer، Arabic-Indic digits، WHT.
- [ ] بەکارهێنانی سکریپتی ڕاهێنان (ku/ar) — بڕوانە `docs/training/scripts/` ئەگەر بەردەستە.
- [ ] دابینکردنی KB/help-articles بە کوردی/عەرەبی.
- [ ] دیاریکردنی «champion» لەناو تیمی کڕیار کە دەبێتە پەیوەندیدار.

---

## 4. مەترسەی سەرکەوتن (Success Metrics)

| مەترسە | پێناسە | ئامانجی pilot *(خەمڵاندن)* |
|--------|---------|------------------------------|
| **Activation** | کڕیار یەکەم فاکتور/فرۆشتنی ڕاستەقینەی تۆمار کرد | لە ٧ ڕۆژی یەکەم |
| **Daily Active Use** | بەکارهێنانی ڕۆژانە (POS/فاکتور) | ≥ ٥ ڕۆژ لە هەفتە |
| **NPS** | Net Promoter Score | ≥ +٣٠ (سەرەتا)، ≥ +٥٠ (ئامانج) |
| **CSAT** | ڕەزامەندی دوای پشتیوانی | ≥ ٤/٥ |
| **Data accuracy** | باڵانس/ئەنبار = واقیع | ٠ ناتەبایی گەورە |
| **Support tickets** | ژمارەی کێشە/هەفتە | کەمبوونەوە بەرەو ٠ |

---

## 5. پلانی 30/60/90 ڕۆژ

### ٣٠ ڕۆژی یەکەم — «کارکردن»
- [ ] migration + training تەواو.
- [ ] کڕیار بەتەواوی POS/فاکتور بەکاردەهێنێت بۆ کاری ڕۆژانە.
- [ ] یەکەم e-Fakhata submission (ئەگەر مەرج بوو).
- [ ] check-in هەفتانە + بەدواداچوونی tickets.
- [ ] **تاقیکردنەوەی offline POS لە کاتی پچڕانی کارەبا** (Iraq-specific).

### ٦٠ ڕۆژ — «قووڵبوون»
- [ ] بەکارهێنانی مۆدیوولی زیاتر (ئەنبار، کڕین، ڕاپۆرت).
- [ ] reconciliation-ی مانگانە + closing.
- [ ] NPS/CSAT survey-ی یەکەم.
- [ ] چارەسەری کێشە/فیدباکی سەرەکی.

### ٩٠ ڕۆژ — «بڕیار»
- [ ] هەڵسەنگاندنی KPI-ەکان (activation، daily use، NPS).
- [ ] گفتوگۆی exit-to-paid (بەشی ٦).
- [ ] کۆکردنەوەی case study / testimonial (ئەگەر سەرکەوتوو بوو).

---

## 6. مەرجی گواستن بۆ پارەدەر (Exit-to-Paid Criteria)

کڕیار ئامادەیە ببێتە پارەدەر کاتێک **هەموو** ئەمانە ڕاست بن:

- [ ] **Activation**: کاری ڕاستەقینەی ڕۆژانە (نە تەنها تاقیکردنەوە).
- [ ] **Data**: باڵانس/ئەنبار دروست + متمانەپێکراو.
- [ ] **NPS ≥ +٣٠** و CSAT ≥ ٤/٥.
- [ ] **پشتیوانی**: tickets-ی کریتیکاڵ = ٠.
- [ ] **Offline POS** بە سەرکەوتوویی لە کاتی پچڕانی کارەبا تاقیکراوەتەوە.
- [ ] **e-Fakhata** (ئەگەر مەرج بوو) submission-ی سەرکەوتوو.
- [ ] خاوەنی بزنس بەرکەوتن (commitment) بۆ نرخی مانگانە دەردەبڕێت.

---

## 7. تایبەتمەندی عێراق — Checklist (Iraq Specifics)

- [ ] **Offline POS test**: کارەبا بکوژێنەرەوە/wifi بپچڕێنە → POS هەر کار دەکات (IndexedDB)، sync دوای گەڕانەوە.
- [ ] **IQD cash drawer**: cash breakdown + denominations (١٠٠٠/٢٥٠/...) + quick-cash tenders تاقی بکەرەوە.
- [ ] **Arabic-Indic digits**: digit preference بگۆڕە و فاکتور/ڕیسیت پشتڕاست بکە.
- [ ] **WhatsApp**: کانگای پەیوەندی/پشتیوانی بە WhatsApp ڕێک بخە (بازاڕی عێراق).
- [ ] **چاپکەری ٥٨/٨٠mm + cash drawer**: pairing wizard + test print + drawer kick.
- [ ] **زمان**: UI بە کوردی/عەرەبی، RTL دروست.
- [ ] **e-Fakhata cert**: ئەگەر کڕیار B2B-ـە، PKCS#12 cert upload + test submission (دوای MoF verification).
- [ ] **Hijri calendar**: ئەگەر کڕیار پێویستی هەیە، calendar toggle تاقی بکەرەوە.
