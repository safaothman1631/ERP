# Pilot Candidate Scoring Rubric (T-SF.6.2)

> Spec: scale-foundation SF6, design.md §6.1.
> Use this to score the 12-candidate shortlist (T-SF.6.1) and pick the top 5 (T-SF.6.3).

## How to score

For each candidate, score each criterion **0–5** on the raw scale below, then multiply by the criterion **weight**. Sum the weighted scores. Rank candidates by total. Aim for the **top 5** while making sure the portfolio satisfies the diversity goals (≥5 sectors, ≥3 governorates) — if the raw top-5 over-concentrates one sector or city, swap in the next-ranked candidate that restores diversity and record the override in the notes column.

**Yes-rate planning:** expect a **2-of-3** outreach yes-rate with a founder warm intro, so a top-5 target implies reaching out to ~7 candidates (which is why the shortlist is 12).

## Raw 0–5 scale (anchors)

| Score | Meaning |
|-------|---------|
| 0 | Absent / disqualifying |
| 1–2 | Weak |
| 3 | Acceptable |
| 4 | Strong |
| 5 | Ideal |

## Criteria & weights (design §6.1)

| # | Criterion | Weight | Raw (0–5) | How to judge |
|---|-----------|:------:|:---------:|--------------|
| 1 | **Sector diversity** (contributes a sector not yet represented in the cohort) | **3×** | | 5 if it adds a brand-new sector; lower if it duplicates a sector already picked |
| 2 | **Geographic diversity** (adds a governorate) | **2×** | | 5 if a new governorate (Erbil / Sulaymaniyah / Baghdad / Mosul / …); lower if duplicating |
| 3 | **Transaction volume potential** (≥ 50/day) | **2×** | | 5 ≥ 150/day; 4 ≥ 100; 3 ≥ 50; 1 < 30 |
| 4 | **Founder relationship / trust** | **1×** | | 5 = close prior relationship; 3 = warm intro; 1 = cold |
| 5 | **Willing to be a public reference** | **2×** | | 5 = enthusiastic, on record; 3 = maybe; 0 = confidential-only |
| 6 | **EN / KU / AR support capability** | **1×** | | 5 = staff comfortable in a language we support well; lower if language friction expected |
| 7 | **Owner-operator** (decision-maker accessible) | **2×** | | 5 = owner runs the shop daily; 1 = absentee owner / committee |

**Maximum possible weighted score:** (3+2+2+1+2+1+2) × 5 = **13 × 5 = 65**.

## Disqualifiers (auto-pass regardless of score)

- No reliable way to reach the decision-maker weekly.
- Unwilling to use the system as primary (parallel-only).
- Operating in a line of business prohibited by the Acceptable Use Policy / Iraqi law.
- Cannot accommodate an on-site Day-0 deploy + training within the program window.
